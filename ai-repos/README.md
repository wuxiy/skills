## 收录标准

一份 AI 时代仓库值得收进来，至少满足其一：

- **对 AI 编码工作流有真实增效**（省时间 / 少返工 / 提升产出一致性）
- **解决 AI 时代特有的痛点**（上下文污染、UI 越写越乱、规则散落、代码腐化）
- **社区验证度高**（star 数、活跃度、实际项目中用过）
- 每个条目附[模板](_template.md)：定位、安装/用法、使用场景、效果、注意点。
