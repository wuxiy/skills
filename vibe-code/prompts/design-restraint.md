# 设计克制三原则（字重 / 留白 / 色彩）

> 一套贴在 UI / 页面生成任务上的设计规范，专治 AI 产出的"满屏颜色、喧闹粗糙、没有呼吸感"界面。极简、可复制、任何 Agent 可用。

## 规范原文（复制即用，附在设计任务 prompt 头部）

### 1. 字重对比
- 标题要足够粗，正文要足够细、足够淡
- 多用中性色，减少锐利和嘈杂感

### 2. 极致留白
- 页面要"宁可空着，也要有呼吸感"
- Padding / Margin 比常规页面大约 **1.5 倍**，让内容显得更高级、更从容

### 3. 克制色彩
- 整体用 **90% 中性色**：白 / 灰 / 黑
- 只保留 **10% 核心色**，通常是**单一强调色**
- 色彩服务于内容层级，避免抢走注意力

## 为什么有效

- AI 默认输出偏"填满每一寸像素 + 彩虹色标签"：信息密度过高、锐利感强、显得廉价。这三条正好反向约束。
- **字重对比**建立视觉层级，不靠颜色也能让人一眼分清主次。
- **极致留白**是最便宜的"高级感"：内容少而不空，是克制的品质感。
- **90/10 色彩**把注意力还给内容，强调色只在真正要"被看见"的地方出现。

## 使用方式

UI / 页面 / 组件生成任务，在 prompt 里直接附上三原则；可配合 [ai-ui-styling](../experience/ai-ui-styling.md)（喂配色规范图）与 [前端感知性能](../experience/perceived-performance.md) 一起用，构成完整的前端体验规范。

## 注意点

- 定量规则（1.5 倍留白、90/10 色彩）是基准，不要逐像素教条化，以"整体从容、层级清楚"为验收标准。
- 如果产品本身需要强品牌色，10% 核心色换成品牌色即可，中性色比例保持不变。
