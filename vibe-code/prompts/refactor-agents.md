# 重构 AGENTS.md（渐进式披露）

把一个堆满指令的 AGENTS.md 按"渐进式披露"原则重构：根文件只留每个任务都相关的内容，其余按类别拆到独立文件。遇到相互冲突的指令时，让 AI 先问你保留哪一版，而不是擅自决定。

## 模板

> 我想让你重构我的 AGENTS.md 文件，使其遵循渐进式披露原则。
>
> 按照以下步骤操作：
>
> 1. **查找矛盾**：识别任何相互冲突的指令。对于每个矛盾，向我询问我想保留哪个版本。
>
> 2. **识别核心内容**：仅提取属于根 AGENTS.md 的内容：
>    - 一句话的项目描述
>    - 包管理器（如果不是 npm）
>    - 非标准的构建 / 类型检查命令
>    - 任何真正与每个任务都相关的部分
>
> 3. **分组其余内容**：将剩余指令组织成逻辑类别（例如，TypeScript 约定、测试模式、API 设计、Git 工作流程）。为每个组创建一个单独的 Markdown 文件。
>
> 4. **创建文件结构**：输出：
>    - 一个简化的根 AGENTS.md，包含指向单独文件的 Markdown 链接
>    - 每个单独文件及其相关指令
>    - 建议的 docs/ 文件夹结构
>
> 5. **标记删除**：识别任何属于以下的指令：
>    - 冗余的（代理已经知道这个）
>    - 过于模糊而无法行动
>    - 过于明显（如"编写干净的代码"）
